# 开源准备检查报告

检查日期：2026-10-08。版本：`0.3.0-oss.1`。本报告针对这个独立副本，不表示私人桌面版已升级依赖，也不表示代码已发布到 GitHub。

## 结论

源码副本已剔除私人配置、记录、旧导入样本、真实研究截图和运行产物，并通过独立安装依赖、测试、前端构建、桌面打包及实际启动检查。所有者已选择 MIT，正式 LICENSE 与包信息已补齐；公开发布前需完成仓库与维护者设置。

## 检查发现与处理

| 事项 | 原项目问题 | 副本处理 |
| --- | --- | --- |
| 私人配置 | 本机环境文件、加密设置与运行记录不适合公开 | 使用明确文件清单复制，未复制这些文件；提供空密钥 `.env.example` |
| 隐藏研究片段 | 旧演示、注释、导入样本与测试混入实际研究内容 | 重写为虚构传感器校准演示，替换测试片段与默认标题；历史资料全部排除 |
| 程序隔离 | 相同桌面标识可能读取原版的数据 | 独立产品名、appId、安装标识、快捷方式、数据目录及存储键；浏览器改为 5290 端口 |
| 自动迁入 | 原启动器会尝试迁入邻近环境配置 | 副本取消自动迁入；用户可在设置中自行填写或主动导入 |
| 依赖安全 | 初次 npm audit：前端 11 项、桌面构建依赖 8 项 | 更新 Vite、KaTeX；统一 Mermaid 的 KaTeX；修复 Electron 下载依赖链；删除未使用旧 UI 与 Tailwind 依赖 |
| 可重复运行 | 一次性 UI 检查脚本绑定私人电脑路径 | 未纳入这些脚本；保留核心/服务端及桌面单元测试和 Windows/Linux CI |
| 发布文档 | 缺少对外贡献与隐私说明 | 新 README、CONTRIBUTING、SECURITY、第三方说明、隐私检查脚本及 CI |
| 代码许可 | 原项目尚无明确许可证 | 已按所有者选择添加 MIT License，版权署名 junru-a and contributors |

依赖整改参考官方维护者安全公告：[Vite / launch-editor](https://github.com/vitejs/launch-editor/security/advisories/GHSA-v6wh-96g9-6wx3)、[KaTeX](https://github.com/KaTeX/KaTeX/security/advisories/GHSA-238p-pmpm-9mq7)。桌面工具链问题由 npm 安全数据库报告的 `sprintf-js` 问题沿依赖链传播；替换该下载依赖后再次审计为零项。
