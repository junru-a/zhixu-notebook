# v0.3.0-oss.1 · 首个公开预览版

知序是一个本地科研记录工具，用项目、研究节点、时间记录和可追溯链接帮助研究者整理自己的工作。

## 可用功能

- 多项目记录、树形研究节点、四色进展与独立科学判定。
- Markdown、LaTeX、Mermaid 阅读与编辑。
- 科研树卡片拖动、网格吸附、自由平移和 Ctrl + 滚轮缩放。
- 知识网络、正文双链、别名、标题/段落引用、反向引用和断链修复。
- 多目录代码索引，可选 DeepSeek 架构分析与有证据的关联建议。
- Windows 桌面应用、系统托盘、本机保存与 JSON 备份。

## 使用

Windows 10/11 x64 用户可安装 Release 的 `*-Setup.exe`。源码运行与编译方式见 README。

首次启动为空项目，演示内容完全虚构。AI 需要自己的 API Key；没有密钥也可以使用本地记录功能。启用 AI 后选定内容会发送给服务提供商，按自己的账户计费。

安装版使用独立的开源版数据目录；关闭窗口会隐藏到托盘，托盘菜单中选择退出可结束程序。

## 版本说明

这是预览版，未配置代码签名证书。安装包附 SHA-256 清单。请定期导出记录备份；报告问题时使用脱敏复现。

架构分析来自有限源码片段与静态线索，不是完整语法树或运行时追踪；尚未测量真实 AI 准确率。当前不提供云同步、多人协作或其他平台桌面安装包。
